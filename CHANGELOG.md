# Изменения

Заметные изменения по версиям. Формат понятен пользователю: что нового, что
исправлено.

## v1.4

Новое:

- **Автопроверка доступности VPN.** Бот предупреждает, если сервер потерял выход
  в интернет или если все активные клиенты разом отключились (возможная
  блокировка провайдером). Проверка по требованию: 📊 Статус → «🩺 Проверка
  доступности».
- **Анализ трафика «глазами DPI».** Короткий захват пакетов и отчёт — энтропия,
  размеры, заголовки: насколько трафик отличим от обычного и не торчит ли
  «ванильный» WireGuard. 📊 Статус → «🩺 Проверка доступности» → «🔬 Анализ
  трафика».
- **Смена маскировки.** ⚙️ Сервис → «🕵️ Маскировка»: сменить магические заголовки
  AmneziaWG (H1–H4) на случайные, чтобы у сервера была уникальная подпись и
  ломались сигнатуры DPI. С бэкапом и автооткатом, если VPN не поднимется;
  конфиги перевыпускаются и рассылаются клиентам с кабинетом. Есть опциональная
  автосмена при подозрении на блок (по умолчанию выключена).
- **Канарейка.** Проверка доступности из сети пользователя в России (отдельный
  Linux-хост). Установка прямо из бота: ⚙️ Сервис → «🩺 Канарейка» —
  командой-одностройкой или по SSH. Заодно защищает хост (ufw, fail2ban,
  автообновления, BBR). Тревоги о блокировке приходят в Telegram.
- **Поиск и фильтры клиентов.** В списке «👥 Клиенты» — поиск по имени/IP и
  фильтры (онлайн, отключённые, истекает ≤3 дней). Удобно, когда клиентов много.

Исправлено:

- **Бот больше не зависает** при долгих операциях (проверка сети, анализ трафика,
  смена маскировки, установка канарейки по SSH): каждое действие обрабатывается
  в своём потоке и не блокирует ответы на остальные нажатия.
- **Бот отвечает быстрее**: состояние клиентов и файлы читаются напрямую (без
  медленных вызовов внутрь контейнера), загрузка CPU считается без задержки.

Важно:

- Функции, меняющие параметры сервера (смена маскировки), перезапускают VPN
  (~10 c) и требуют новых конфигов у клиентов — бот перевышлет их тем, у кого
  есть кабинет. Обычное обновление набора клиентов не затрагивает.
