# VPN Server Kit

Набор надстроек для собственного VPN-сервера на **Amnezia (AmneziaWG)**: блокировка российских ресурсов для клиентов VPN, свой DNS с фильтрацией, защита сервера и Telegram-бот для управления. Ставится одной командой поверх сервера, который вы уже настроили через приложение AmneziaVPN.

## Возможности

**Сервер и сеть**

- **Блокировка российских IP** для клиентов VPN: список сетей RU (около 8–9 тысяч) обновляется еженедельно. Соединения клиентов из России к самому VPN не затрагиваются.
- **AdGuard Home как DNS для всех клиентов**:
  - блокирует рекламу, трекеры и, по желанию, домены `.ru/.рф/.su`;
  - перехватывает DNS-запросы клиентов на сервере, поэтому на устройствах ничего настраивать не нужно;
  - если AdGuard упадёт, перехват автоматически снимается, и интернет у клиентов не пропадает.
- **Статистика и настройки по каждому клиенту**: AdGuard видит реальный адрес каждого клиента VPN, а имена подтягиваются из Amnezia.
- **Детский режим для отдельного клиента**: фильтр сайтов для взрослых, безопасный поиск Google, YouTube и Bing, защита от фишинга и запрет обхода фильтра через «Частный DNS» (DNS-over-TLS).
- **Запрет исходящего SMTP (порт 25)**: через VPN нельзя рассылать спам, и хостер не заблокирует сервер из-за жалоб.
- **Межсетевой экран (ufw)**: открыты только SSH и порт AmneziaWG, ping скрыт. Протоколы, добавленные позже через приложение Amnezia, работают без дополнительной настройки.
- **fail2ban**: после 5 неудачных попыток входа по SSH IP блокируется на час.
- **Автоматические обновления безопасности**: если обновилось ядро, сервер перезагружается ночью.
- **BBR**: ускорение TCP.

**Telegram-бот**

- Состояние сервера: процессор, память, диск, трафик, работа VPN и AdGuard.
- Клиенты: кто онлайн, трафик, последние DNS-запросы, детский режим.
- **Новый клиент одной кнопкой**: бот присылает файл `.conf` с QR-кодом и ссылку `vpn://` с QR для AmneziaVPN.
- **Имя сервера для пользователей**: в выданных конфигах `vpn://` сервер отображается в приложении AmneziaVPN под заданным вами именем (⚙️ Сервис → «Имя сервера»).
- **Замена ключа**: все копии конфига перестают работать, а имя, IP и настройки клиента сохраняются.
- **Отключение и включение клиента**.
- **Срок действия клиента**: когда срок истекает, клиент отключается автоматически, а за день бот предупреждает. Кнопка «Продлить».
- **Месячный лимит трафика**: бот сам считает трафик (не сбивается при перезапуске сервера) и отключает клиента при превышении; новый месяц — доступ возвращается. Кнопка «Сбросить лимит».
- **Предупреждение, если один конфиг работает на нескольких устройствах**, с кнопками «Новый ключ», «Отключить» и «Игнорировать».
- **Ежедневный отчёт**: трафик по клиентам, кто онлайн, у кого скоро истекает срок, состояние сервера и AdGuard. Можно переключить на еженедельный или выключить.
- **Зашифрованный бэкап в Telegram** и восстановление на новом сервере одной командой (переезд). Пароль шифрования бот показывает один раз.
- **Обновление из бота**: бот сам замечает новый релиз на GitHub и обновляет набор по кнопке (с проверкой контрольной суммы, настройки сохраняются).
- Уведомления: VPN или AdGuard упал, заканчивается место на диске, сервер перезагрузился, новый клиент подключился впервые.
- Файл для раздельного туннелирования «российские сайты без VPN», готовый к импорту в AmneziaVPN.
- Управление блокировкой RU и AdGuard, перезапуск сервисов, перезагрузка сервера.

## Требования

- VPS с **Ubuntu 22.04+** или **Debian 12+**, от 1 ГБ памяти.
- **AmneziaWG**, установленный на этот сервер через приложение [AmneziaVPN](https://amnezia.org): «Добавить сервер» → «Свой сервер» → AmneziaWG. Приложение само ставит Docker и создаёт контейнер `amnezia-awg*`.
- **Отдельный Telegram-бот для каждого сервера**: создайте его через [@BotFather](https://t.me/BotFather) (`/newbot`) и сохраните токен. Один токен нельзя запустить на двух серверах одновременно.

## Установка

Подключитесь к серверу по SSH под `root` и выполните одну команду:

```bash
bash <(curl -fsSL https://github.com/s1riller/amnezia-server-kit/releases/latest/download/install-vpn-kit.sh) --token 1234567890:AAH...
```

Установка занимает 2–5 минут. В конце скрипт проверяет результат и печатает код:

```
Чтобы стать администратором бота, отправьте ему:   /start 1a2b3c4d
```

Отправьте эту строку своему боту, и он откроет меню.

### Если хотите сначала посмотреть скрипт

К каждому релизу приложена контрольная сумма: по ней видно, что файл скачался целиком и совпадает с опубликованным.

```bash
curl -fsSLO https://github.com/s1riller/amnezia-server-kit/releases/latest/download/install-vpn-kit.sh
curl -fsSLO https://github.com/s1riller/amnezia-server-kit/releases/latest/download/install-vpn-kit.sh.sha256
sha256sum -c install-vpn-kit.sh.sha256
less install-vpn-kit.sh
bash install-vpn-kit.sh --token 1234567890:AAH...
```

### С компьютера на Windows

В PowerShell:

```powershell
ssh root@<IP-сервера> "bash <(curl -fsSL https://github.com/s1riller/amnezia-server-kit/releases/latest/download/install-vpn-kit.sh) --token <ТОКЕН>"
```

### Параметры

| Параметр           | Что делает                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------------- |
| `--token <токен>`  | токен бота. Можно задать позже на сервере: `vpn-bot-token <токен>`                            |
| `--no-ru-block`    | не блокировать российские IP                                                                  |
| `--no-ru-dns`      | не блокировать домены `.ru/.рф/.su` в AdGuard ([почему это важно](#российские-сайты-без-vpn)) |
| `--no-adguard`     | без AdGuard: не будет своего DNS, статистики по клиентам и детского режима                    |
| `--no-auto-reboot` | не перезагружать сервер после обновлений ядра                                                 |
| `--no-bot`         | без Telegram-бота                                                                             |
| `--uninstall`      | удалить набор, см. [Удаление](#удаление)                                                      |

Параметры запоминаются в `/etc/vpn-kit/options`, поэтому при обновлении их не нужно повторять. Включить компонент обратно: `--ru-block`, `--ru-dns`, `--adguard`, `--auto-reboot`, `--bot`. Если переключить блокировку RU в боте, выбор тоже сохранится.

## После установки

- **Пароль root.** Если он где-то пересылался, смените его командой `passwd`, а лучше настройте вход по SSH-ключу.
- **Часовой пояс.** Ночная перезагрузка идёт в 04:00 по времени сервера, у многих хостеров это UTC. Сменить пояс: `timedatectl set-timezone Europe/Moscow`.
- **Веб-панель AdGuard**: <http://172.29.172.253>. Она открывается только при подключённом VPN. Логин и пароль выводит команда `cat /root/adguard-admin.txt`, также они есть в боте в разделе 🛡 AdGuard.
- **Другие администраторы бота.** Человек пишет боту и получает в ответ свой ID, затем вы отправляете `/addadmin <ID>`.

Команды бота: `/menu`, `/status`, `/clients`, `/add <имя>`, `/addadmin <id>`, `/deladmin <id>`, `/admins`.

## Российские сайты без VPN

В AmneziaVPN есть раздельное туннелирование по IP-адресам. Бот готовит для него файл: 🇷🇺 Блокировка RU → «📲 Файл "российские сайты без VPN"». Файл и инструкцию можно переслать пользователям, а они один раз импортируют его в приложении:

Настройки → Раздельное туннелирование → Сайты → «Адреса из списка не должны открываться через VPN» → ⋮ → Импорт → «Заменить список».

> **Важно:** в этом случае выключите блокировку доменов `.ru` (бот: 🇷🇺 Блокировка RU → «Выключить блок доменов», или установка с `--no-ru-dns`). DNS-запросы всё равно идут через VPN, и AdGuard не даст открыть российские домены даже напрямую. Блокировку по IP можно оставить: она подстрахует тех, у кого список не импортирован.

Зашить исключения прямо в конфиг клиента (`AllowedIPs`) нельзя: точный список «всё, кроме России» — это около 22 тысяч маршрутов, такой конфиг слишком велик для телефонов.

## Как это устроено

| Компонент                             | Как работает                                                                                                                                                                                                                                                                  |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Блокировка RU                         | `ipset` с сетями RU (источник [ipdeny.com](https://www.ipdeny.com), запасные — [ipverse](https://github.com/ipverse/rir-ip) и RIPE). Правило в цепочке `DOCKER-USER` отклоняет только **новые исходящие** соединения, поэтому клиенты из России подключаются к VPN как обычно |
| DNS → AdGuard                         | DNAT порта 53 внутри контейнера VPN на AdGuard (`172.29.172.253`, сеть `amnezia-dns-net`). Проверка каждую минуту: если AdGuard не отвечает, перенаправление снимается                                                                                                        |
| Реальные IP клиентов в AdGuard        | для DNS-трафика отключена подмена адреса (маскарад), добавлены обратные маршруты к подсети клиентов                                                                                                                                                                           |
| Синхронизация с AdGuard               | `adguard-sync-clients` создаёт в AdGuard клиента для каждого пира AmneziaWG с именем из Amnezia. Если IP достаётся другому ключу, настройки сбрасываются, чтобы детский режим не перешёл к другому человеку                                                                   |
| Клиенты из бота                       | бот пишет в те же файлы, что и приложение Amnezia (`awg0.conf`, `clientsTable`), поэтому созданные в боте клиенты видны в приложении и наоборот. Перед каждым изменением делается резервная копия                                                                             |
| Один конфиг на нескольких устройствах | бот раз в 3 секунды читает состояние пиров. У одного устройства за 5 минут 0 смен адреса и около 3 рукопожатий, у двух устройств с одним ключом — от 4 смен и 10 рукопожатий. Порог: ≥ 3 смен адреса и ≥ 7 рукопожатий за 5 минут, или ≥ 10 смен адреса                       |
| Устойчивость                          | правила внутри контейнера VPN проверяются и восстанавливаются каждую минуту и после перезапуска Docker                                                                                                                                                                        |

Все сервисы — это обычные юниты systemd: `block-ru`, `vpn-net`, `vpn-bot`. Бот написан на Python и использует только стандартную библиотеку.

## Обновление

Проще всего — из бота: ⚙️ Сервис → «Обновить набор». Бот скачает последний релиз, проверит контрольную сумму и перезапустит сервисы; о новой версии он и сам сообщит. Настройки при этом сохраняются.

Вручную — запустите ту же команду установки, токен указывать не нужно:

```bash
bash <(curl -fsSL https://github.com/s1riller/amnezia-server-kit/releases/latest/download/install-vpn-kit.sh)
```

Повторный запуск безопасен: токен, администраторы, клиенты, отключённые клиенты, детский режим, настройки AdGuard, сроки и лимиты клиентов и параметры установки сохраняются, правила не дублируются.

## Бэкап и переезд на другой сервер

В боте: ⚙️ Сервис → «Бэкап в Telegram». Бот пришлёт зашифрованный архив (клиенты, ключи, сроки и лимиты, настройки AdGuard и бота) и **один раз** покажет пароль — сохраните его, без него восстановить нельзя.

Чтобы перенести всё на новый сервер: поставьте там AmneziaWG через приложение Amnezia, скопируйте архив на сервер и выполните

```bash
bash <(curl -fsSL https://github.com/s1riller/amnezia-server-kit/releases/latest/download/install-vpn-kit.sh) --restore vpn-kit-backup-ГГГГММДД-ЧЧММСС.tar.gz.enc
```

Скрипт спросит пароль бэкапа, восстановит данные и доустановит набор. Клиенты, их настройки и доступ к веб-панели AdGuard останутся прежними.

## Удаление

```bash
bash <(curl -fsSL https://github.com/s1riller/amnezia-server-kit/releases/latest/download/install-vpn-kit.sh) --uninstall
```

Скрипт покажет, что будет удалено, и спросит подтверждение; `--yes` отключает вопрос. Удаляются бот, AdGuard Home, блокировка RU и правила для клиентов VPN, после чего контейнер VPN перезапускается с чистыми правилами (клиенты переподключатся примерно за 10 секунд).

Остаются AmneziaWG и все клиенты, включая созданных через бота. Клиенты, которых вы отключили в боте, после удаления снова получат доступ, поэтому ненужных удалите заранее. Также остаются ufw, fail2ban, автообновления и BBR: это обычная защита сервера, ufw при желании отключается командой `ufw disable`.

## Конфиденциальность

AdGuard хранит журнал DNS-запросов 24 часа и статистику 7 дней. Администратор видит, какие сайты открывал каждый клиент. Предупредите об этом пользователей своего VPN. Срок хранения журнала можно сократить или отключить журнал в веб-панели AdGuard: «Настройки» → «Настройки DNS» → «Журнал запросов».

## Сборка из исходников

`install-vpn-kit.sh` — это собранный файл: шаблон `src/install.template.sh` плюс встроенные в него файлы из `src/`. После правок пересоберите его:

```bash
python3 src/build.py                       # результат: ./install-vpn-kit.sh
python3 -m unittest discover -s tests -v   # тесты бота (Linux, без Docker и Telegram)
```

Файлам нужны окончания строк LF, сборщик приводит их к LF сам.

GitHub Actions на каждый push проверяет, что `install-vpn-kit.sh` пересобран из `src/`, прогоняет shellcheck и тесты на Python 3.10–3.12. Релиз создаётся тегом, совпадающим с `KIT_VERSION` в `src/install.template.sh`: `git tag v1.1 && git push origin v1.1`. К релизу прикладываются установщик и его контрольная сумма SHA-256.

## Совместимость и статус

Версия **1.2**. Проверено на Ubuntu 26.04, AmneziaWG 2 (контейнер `amnezia-awg2`), AdGuard Home v0.107.80: каждый компонент на рабочем сервере и повторный запуск установщика поверх существующей установки. Установка на новый сервер «с нуля» пока проверена мало, поэтому первый раз лучше попробовать на тестовом VPS. Об ошибках пишите в [Issues](../../issues).

- Блокировка RU и запрет SMTP действуют для всех протоколов Amnezia на сервере.
- Бот, AdGuard по клиентам и детский режим работают с AmneziaWG.
- Нужна стандартная сеть Amnezia `amnezia-dns-net` (`172.29.172.0/24`).

## Отказ от ответственности

Проект не связан с командой Amnezia. Скрипт выполняется от root и меняет настройки сети и межсетевого экрана сервера; используйте его на свой риск и в соответствии с законодательством вашей страны.
